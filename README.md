# CSV Merger

Скрипт на Python, который берёт все CSV-файлы из папки `data` и склеивает их в один Excel-файл `итог.xlsx`.

## Что делает

- Находит все `.csv` файлы в папке `data`
- Читает каждый файл через pandas
- Склеивает все таблицы в одну
- Сохраняет результат в `итог.xlsx`

## Как запустить

1. Установи зависимости:
`pip3 install pandas openpyxl` (в терминал)

2. Положи свои CSV-файлы в папку `data`

3. Запусти скрипт:
`python3 merge.py` (в терминал)

4. Открой файл `итог.xlsx` — там будут все данные из CSV.

## Технологии

- Python 3
- pandas
- openpyxl
